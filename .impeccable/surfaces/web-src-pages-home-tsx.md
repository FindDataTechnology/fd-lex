# Surface brief — web/src/pages/Home.tsx (识律 Lex 官网静态面)

## Scope & mode
Single-page marketing site + anchors (capabilities / pricing / private-deployment docs); `/console` and `/admin` remain untouched placeholders. Mode: **Persuade**. Bilingual zh (default) / en with strict structural parity (i18next).

## Audience, job, action
- Audience: enterprise legal departments, legal-tech procurement, integrators evaluating private deployment (B2B legal).
- Job: understand that 识律 = legal data · apps · models, vertically integrated, shipped as ONE versioned distribution package with two hosts (cloud / customer machine room).
- Action: enter console, or request a quote (contact channel placeholder).
- Proof: real asset facts from specs only — 1,050万 judgments, 32,275 statute catalog entries, 52 LawBench tools, judge_c/drafter_a models, three data tiers. No invented prices, endpoints, hardware numbers, emails.

## Constraints (brief-pinned)
- Legal-industry B2B: restrained, credible, generous whitespace, NO flashy motion. Chinese primary, English parity.
- Hosting annotations must be truthful: models = on-prem only (cloud inference/API NOT in v1, listed v1.x); distribution pack = on-prem side; retrieval/contract-intelligence/API-MCP = dual host.
- Pricing section presents billing DIMENSIONS only, all values "quote on request"; numbers are admin-configured, not pre-filled.

## Direction contract
THESIS: the site performs its own deliverable — the capability catalog is typeset like a statute register/legal ledger, so the visitor audits capabilities and host annotations the way they would audit a legal document; it refuses the SaaS card-grid landing grammar.
OWN-WORLD: cool paper ground (#F6F7F9, not cream) + statute-book navy owning whole regions (hero, footer) (#122E56) + ink-slate body (#1C2B42) + seal vermilion (#A6402F) appearing at exactly two meanings: the brand seal and the truthful on-prem-only marking. Display face: Noto Serif SC (Songti lineage, legal/official-document register), self-hosted; body: system CJK sans stack. 1px ruled register rows instead of cards.
STORY: visitor reads the three-layer stack in the first viewport (data → apps → models, one package, two hosts); scrolls a ruled catalog where every row's host availability is honestly badged (models' missing cloud offering stated, which builds trust); pricing shows dimensions with "quote on request"; docs explain deploy/upgrade/incremental-update/offline in document register; acts via console CTA or contact.
FIRST VIEWPORT: paper header (seal mark + 识律 Lex · anchors 能力/定价/私有化交付 · console + language toggle); below it a statute-navy hero split 7:5 — left: Songti display two-line positioning (法律数据 · 应用 · 模型 / 垂直整合，全栈可私有化), lede, proof stat line, dual CTA; right: three-layer vertical-stack diagram with per-layer host tags and a bracket caption "同一份交付包 · 双宿主". Seal red only on the brand seal within viewport one.
FORM: code-led (no image generation in this harness); surface scope precisely specified by the brief (five-block anchor page), brief-pinned direction beats the roll; no concept-seed run. Signature interaction: none beyond smooth anchor scroll and one restrained hero entrance — restraint is the pinned register.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
