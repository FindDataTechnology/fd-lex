Architecture & Private Deployment

Live platform shape, delivery-package composition, data governance, deployment roadmap. Planned capabilities are labelled v1.x.

Live platform shape (one domain, four entries)

Entries & identity

  • Four entries: website & capability catalog / customer console (sign-up → mint a long-lived key → usage & billing) / MCP API / delivery page
  • Tenant isolation: a dedicated customer identity organization with minimal scope — a customer key only sees the services it purchased; out-of-scope calls are rejected (403)

Services & metering

  • Legal retrieval MCP: 10 tools [N7] — statutes / similar cases / guiding cases; every result carries provenance (source database, stable identifier, as-of time)
  • Dual-unit metering: reads by row, generation by call; the settlement ledger is authoritative with three-way reconciliation
  • Fail-closed: hard stop on exhausted quota (preflight rejection, 402); warnings archived at the 80% and 95% tiers [N16]

Data governance & updates

Scale & tiers

  • 32,296 laws and regulations [N1] · 364,916 statute chunks [N2] · 47,256 authoritative documents [N6]
  • Court judgments 37,001,012 [N4]; the full judgments package is approx. 175GB [N15], delivered after per-project legal review

Update mechanics

  • Pull-based increments: customers pull daily / weekly updates from distribution endpoints on a schedule — credential-authenticated, sha256-verified, resumable
  • Offline full-package fallback: content-equivalent to the online channel, built for air-gapped networks
  • Versioned builds: packages are versioned with component digests locked; injecting cloud-only dependencies fails the build

Deployment roadmap

Install & upgrade v1.x planned

  • Single-machine docker compose install; data lands in local volumes
  • Reinstall-style upgrades: version advances preserve customer data (corpora / artifacts / configuration)
  • Air-gapped operation supported for reference / corpus package scenarios

Where things stand today

  • The cloud host is live: entries, console, metering & settlement, legal retrieval — the full chain is in service
  • Private delivery packages are scheduled per customer engagement; scope and progress follow the contract and the delivery page
