在役平台形态（单域四入口）

入口与身份

  • 单域四入口：官网与能力目录 / 客户控制台（注册→铸造长命密钥→用量账单）/ MCP API / 交付页
  • 租户隔离：独立客户身份组织，最小 scope——客户密钥仅可见所购服务，越界调用拒绝（403）

服务与计量

  • 法律检索 MCP：10 个工具 [N7]——法条 / 类案 / 指导案例检索，每个结果带 provenance（来源库、稳定标识、口径时间）
  • 双单位计量：读取类按行、生成类按次；结算账本权威，三方对账一致
  • fail-closed：额度耗尽硬停（预检拒绝 402），80% / 95% 两档预警留档 [N16]

数据治理与更新

规模与分层

  • 法律法规 32,296 部 [N1] · 法条切片约 36.5 万 [N2] · 权威语料 30,151 件 [N6]
  • 裁判文书约 3,700 万篇 [N4]，全量文书包约 175GB [N15]，按项目法务过审后交付

更新机制

  • 增量拉模式：客户侧定时经分发端点拉取日更 / 周更，凭据鉴权 + sha256 完整性校验 + 断点续传
  • 离线整包兜底：与在线通道内容等价，适配隔离网络
  • 版本化构建：交付包按版本组织，组件 digest 锁定，云专属依赖注入即构建失败

部署路线

  • 引用包 / 语料包场景支持无外网运行
